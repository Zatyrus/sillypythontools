# Silly Python Tools
A random collection of silly tools written in Python. (What did you expect? :>). I'll occasionally dump some of my random Python scripts here, so check back every once in a while. If you have any suggestions for tools I should write, feel free to contact me.

## Installation
1. Clone this repository.
2. Get Astral [uv](https://docs.astral.sh/uv/getting-started/installation/).
3. Choose the tool you want from the table below and run the group sync command through uv:
```bash
uv sync --group <tool_name>
```
4. Change the parameters in the script to your liking and run it.
5. Enjoy!

## Tools
| Tool Name | Group | Description |
|-----------|-----------|------------|
| QR Code Generator | qr | Generates a QR code from a given string and saves it as an image file. Comes with a customizable border size. |
| Timed URL Caller | url-caller | Calls a URL at a specified interval and displays the results. Comes with a progress bar and rich output. |
